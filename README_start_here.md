# VLog字幕ツール セットアップガイド

このフォルダーには VLog字幕ツールを **Pythonをインストールせずに** 利用するための同梱ランタイムが含まれています。以下の手順に従い、アイコンをクリックするだけでアプリを起動できます。

## 1. インストール手順

### Windows 10/11
1. `run.bat` を右クリックして **「ショートカットの作成」** を選択します。
2. 作成されたショートカットをデスクトップなど使いやすい場所へ移動し、必要に応じてアイコンを設定します。
3. 初回起動時は Windows SmartScreen が警告を表示することがあります。表示された場合は「詳細情報」→「実行」を選択してください。

### macOS 13/14/15
1. `run.command` をダブルクリックするとターミナルが開き、アプリが起動します。
2. 初回起動時に Gatekeeper が警告を表示する場合は、`run.command` を右クリックして「開く」を選択し、表示されたダイアログで再度「開く」を押してください。
3. ドックに追加したい場合は、起動後に Dock 上のターミナルアイコンを右クリックし、「オプション」→「Dockに追加」を選択します。

> **ヒント**: macOS でファイルが開けない場合は `chmod +x run.command` を実行し、実行権限を付与してください。

## 2. ログと診断

- アプリの起動ログは以下の場所に保存されます。
  - **Windows**: `%LOCALAPPDATA%\VlogSubsTool\logs\vlog-subs-tool-debug.log`
  - **macOS**: `~/Library/Logs/vlog-subs-tool/vlog-subs-tool-debug.log`
- アプリ起動後に問題が発生した場合は `launch.log` と合わせてサポートへお送りください。
- 事前に依存関係を確認したい場合は、ターミナル／コマンドプロンプトで次を実行します。
  - Windows: `env\Scripts\python.exe -m app.main --check`
  - macOS: `env/bin/python -m app.main --check`

## 3. トラブルシューティング

| 症状 | 対処方法 |
| ---- | -------- |
| `run.bat` / `run.command` を実行しても何も表示されない | ログフォルダーの `launch.log` と `vlog-subs-tool-debug.log` を確認してください。必要に応じて `--check` を実行します。 |
| 「同梱Pythonが見つかりません」と表示される | `env/` フォルダーが削除されていないか確認し、必要であれば管理者に再インストールを依頼してください。 |
| Gatekeeper / SmartScreen の警告が消えない | Windows は「詳細情報→実行」、macOS は「右クリック→開く」で回避できます。詳しくは公式READMEの「セキュリティ警告について」を参照してください。 |

## 4. アップデート方法

1. 新しいバージョンのアーカイブをダウンロードします。
2. 既存フォルダーをバックアップし、新しいフォルダーで置き換えます。
3. `run.bat` / `run.command` のショートカットはそのまま使用できます（フォルダー名を変更した場合はリンクを更新してください）。
